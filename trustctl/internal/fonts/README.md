# Built-in fonts

8x8 fonts (772 bytes, U8x8 format) that `trustctl` carries, generated by `tools/embed_fonts.py` from U8g2's
`u8x8_fonts.c`. Only fonts that may be redistributed are included.

| Name | Source | License |
| --- | --- | --- |
| victoriamedium8 (default), victoriabold8, chroma48medium8, artossans8, artosserif8, torussansbold8 | "A package of 8-bit fonts for Grafx2 and Linux", opengameart.org | CC0 / public domain (https://creativecommons.org/publicdomain/zero/1.0/), as listed by U8g2 in its font group "Open Game Art" |
| 5x8 | X11 "misc fixed" | public domain ("Public domain font. Share and enjoy.") |

Left out on purpose, because their terms need more care than "bundle it": Press Start 2P (SIL OFL with a reserved font
name), PC Senior (codeman38's own license), PxPlus IBM CGA and CGA thin, Amstrad CPC extended. They can still be used
with `trustctl calibrate font FILE.bin` after extracting them with `tools/extract_u8x8_font.py`.
